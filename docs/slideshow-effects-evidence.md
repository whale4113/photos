The following conclusions additionally use exact string-bounded reads of this supplied shipped JavaScript, not observations of the original app running.

- `directorParameters.imageItemDurationMs` is **4000 ms**; the initial slideshow state contains a separate **3000 ms** value, overridden by the director's effective duration. Parent should use 4000 ms and start its timer after `onReady`.
- `animationSelectorOptions`: zoom in/out `.33` each, pan left/right `.17` each. Speeds: zoom `.01/s`, pan `2/300 box/s`. The reconstruction uses those rates over a 16-second finite motion window, allowing normal overlap/slow navigation without unbounded scaling.
- `transitionSelectorOptions` has 12 entries: none `.2`, black fade `.06`, crossfade `.25`, zoom through black in/out `.16` each, zoom fade in/out `.12` each, push left `.12`, push up `.25`, push rotate `.12`, both vertical split variants `.03` each. Weights are relative rather than percentages. Other implemented cases exist but are absent from this shipped default pool: zoomRotate, rotate, elasticStretchLeft, elasticStretchDown, elasticSqueezeVertical. They are supported through optional `transition` override, preserving the original default pool.
- Selection reconstructs `cE` seeded hash and `yE` weighted sampling, the session-wide zoom-family selection, Voronoi minimum push spacing, motion conflicts, image aspect and letterboxing restrictions. Stable slide indices can be supplied with optional `slideIndex`; otherwise encounter indices are used. Cache retains 32 images' metadata, no pixel buffers.
- `sE` and `FE`/`BE`: landscape images use MatchWidth; square/portrait images use MatchHeight. `TT` creates a Fill background only for letterboxing; blur radius is `.01` of texture size, sample count 8. Transparent image background is RGB32. Reconstruction keeps an image cover/blur layer beneath the foreground, visible in margins and transparency; browser CSS Gaussian blur is an approximation to the recovered shader's sampling.
- Exact configured durations: fade/crossfade/split `666.6667 ms`; zoom-through-black fade-out `333.3333 ms`, fade-in `250 ms`, incoming zoom `3000 ms`; zoom fade `1100 ms` plus incoming zoom `3000 ms`; pushes left/up/rotate `2700/3000/2500 ms`; rotate variants out/in `450/475 ms`; elastic out/in `330/500 ms`, squeeze `400/500 ms`.
- Web Animations tracks motion and transitions together for pause/resume. Disabling transitions finishes incoming transforms and removes outgoing layers. Disabling motion cancels foreground animations; enabling restarts current motion. Image loading preserves the previous frame; rapid navigation cancels detached-frame animations. Unmount cancels all animations.

Limitations: CSS transforms/gradient masks replace the original WebGL shader blend/circle masks; exact shader sampling, easing curves, temporal overlap centering and rotation pivots are visually approximated. Enabling motion during a slide restarts motion rather than reconstructing the original absolute timeline. Original application runtime/pixel-equivalence has not been established by this static inspection.
